## 👨‍💻 Sobre mim

Olá! Sou **Edsom Junior**, estudante de Ciência da Computação.

Tenho interesse em desenvolvimento de software, principalmente no ecossistema JavaScript, TypeScript e Node.js, além de trabalhar com SQL.

Meu GitHub reúne projetos de diferentes etapas da minha formação, incluindo exercícios acadêmicos em C# e Python e projetos de desenvolvimento de software.

Utilizo esse espaço para colocar meus conhecimentos em prática, explorar soluções e acompanhar minha evolução como programador.
